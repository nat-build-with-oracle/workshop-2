When to split work across agents — and when not to.

งานวิจัย: Sonnet 6 ตัว — 3 ตัวบน black (สกิล, transcript 110,952 ไฟล์, memory 9,173 ไฟล์) อีก 3 ตัวค้นเว็บ ก.ย. 2026

The price

15×

More agents means about fifteen times the tokens.

ใช้หลายเอเจนต์ กิน token ราวสิบห้าเท่า

Anthropic, multi-agent research system, 2025

Single chat = 1×. Single agent with tools ≈ 4×. Multi-agent ≈ 15×. Anthropic's Jan 2026 follow-up says 3–10× is typical. Either way: it's expensive.

แชตเดี่ยว = 1 เท่า เอเจนต์เดี่ยวมีเครื่องมือ ≈ 4 เท่า หลายเอเจนต์ ≈ 15 เท่า บทความ ม.ค. 2026 บอกว่าปกติอยู่ที่ 3–10 เท่า ยังไงก็แพง

The catch

80%

Most of the gain is just more thinking, not smarter teamwork.

ผลที่ดีขึ้นส่วนใหญ่มาจากคิดเยอะขึ้น ไม่ใช่ทำงานเป็นทีมเก่งขึ้น

Token spend explained 80% of performance variance — same source

The orchestrator beat single-agent Opus 4 by 90.2% on their eval. But 80% of the variance came from token count alone. You're mostly buying compute.

orchestrator ชนะ Opus 4 เดี่ยว 90.2% บน eval ของเขา แต่ 80% ของความต่างมาจากจำนวน token ล้วน ๆ ที่ซื้อมาส่วนใหญ่คือ compute

So when is it worth it?

Only three reasons.

มีแค่สามเหตุผล

01Context is too bigบริบทใหญ่เกิน
02Work is independentงานแยกขาดจากกัน
03A specialist is betterมีตัวเชี่ยวชาญที่เก่งกว่า

Anthropic, "When to use multi-agent systems", Jan 2026

Context protection — the work needs more than one window, or noisy sub-work would pollute the main thread. Parallelization — breadth-first, not a chain. Specialization — a different model/tool/persona measurably wins on one slice. Anything else: single agent.

กันบริบท — งานใหญ่กว่าหน้าต่างเดียว หรืองานย่อยจะมาเลอะ thread หลัก ทำขนาน — แบบกว้าง ไม่ใช่โซ่ เชี่ยวชาญ — โมเดล/เครื่องมือ/บุคลิกอื่นชนะชิ้นนั้นแบบวัดได้ นอกนั้นใช้เอเจนต์เดียว

The one question

Can each agent work without seeing the others?

แต่ละเอเจนต์ทำงานได้ไหม โดยไม่ต้องเห็นงานของตัวอื่น

If no — don't split it.

ถ้าไม่ได้ ก็อย่าแบ่ง

Anthropic's test: "can the context be truly isolated?" Cognition's essay agrees from the other side — agents that can't see each other make conflicting implicit decisions. Their example: one draws a Mario background, another draws a bird that doesn't match.

เกณฑ์ของ Anthropic: "แยกบริบทออกจากกันได้จริงไหม" บทความของ Cognition เห็นตรงกันจากอีกฝั่ง เอเจนต์ที่ไม่เห็นกันจะตัดสินใจโดยนัยขัดกัน ตัวอย่างคือตัวหนึ่งวาดฉาก Mario อีกตัววาดนกที่ไม่เข้ากัน

Shape 1

Fan-out. One asks, many answer, one decides.

กระจาย หนึ่งถาม หลายตอบ หนึ่งตัดสิน

The cheapest way to run in parallel. Most of the fleet's skills are this.

วิธีทำขนานที่ถูกที่สุด สกิลส่วนใหญ่ของฟลีตเป็นแบบนี้

/sonnet N, /oracle-deep-research, /seek --deep, /adversarial-analysis all fan out via the Agent tool. 7 of the fleet's 15 multi-agent skills. Workers are ephemeral; only their final text comes back.

/sonnet N, /oracle-deep-research, /seek --deep, /adversarial-analysis ล้วนกระจายผ่าน Agent tool 7 จาก 15 สกิลหลายเอเจนต์ของฟลีต คนงานเป็นแบบชั่วคราว กลับมาแค่ข้อความสรุป

Shape 2

Pipeline. Each step feeds the next.

ต่อท่อ แต่ละขั้นส่งต่อให้ขั้นถัดไป

Written as a script. Same order every time. Can resume where it stopped.

เขียนเป็นสคริปต์ ลำดับเดิมทุกครั้ง หยุดตรงไหนกลับมาต่อตรงนั้นได้

The Workflow tool: a JS script with agent(), parallel(), pipeline(), phase(). The script itself costs zero tokens. Caps: 16 concurrent, 1,000 agents per run. The fleet started using it 2026-05-29 and it was still ramping in July.

Workflow tool: สคริปต์ JS มี agent(), parallel(), pipeline(), phase() ตัวสคริปต์ไม่กิน token เพดาน: พร้อมกัน 16 รวม 1,000 ต่อรัน ฟลีตเริ่มใช้ 2026-05-29 แล้วยังไต่อยู่ตอน ก.ค.

Shape 3

Adversarial. Five agents try to break one claim.

รุมทุบ ห้าเอเจนต์พยายามทำลายข้อสรุปเดียว

If it survives, trust it. The output is a score, not an essay.

ถ้ารอด ก็เชื่อได้ ผลลัพธ์เป็นคะแนน ไม่ใช่ความเรียง

/adversarial-analysis. Born 2026-06-07 from a real bug: a cross-check found issue #2370's fix wouldn't work, which became #2375. Scores X/5 — 5/5 proceed, 4/5 fix the gap, 3/5 investigate, ≤2/5 don't act.

/adversarial-analysis เกิด 2026-06-07 จากบั๊กจริง การไขว้สอบเจอว่า fix ของ issue #2370 ใช้ไม่ได้ กลายเป็น #2375 ให้คะแนน X/5 — 5/5 ไปต่อ 4/5 อุดช่องก่อน 3/5 สืบเพิ่ม ≤2/5 อย่าเพิ่งทำ

Shape 4

Team. Agents that stay alive and talk to each other.

ทีม เอเจนต์ที่อยู่ยาวและคุยกันเองได้

The most powerful shape — and the most expensive, and the most fragile.

ทรงพลังที่สุด แต่ก็แพงที่สุด และเปราะที่สุด

team-agents (Claude teammates via SendMessage + shared task list), codex-team / oracle-team / trio (external coders over tmux). Anthropic: "significantly higher" cost, each teammate is a full session. Fleet memory: teams "produced stale reports and idle noise"; 50% boot-death on the second spawn; "queued ≠ delivered".

team-agents (เพื่อนร่วมทีม Claude ผ่าน SendMessage + รายการงานร่วม) codex-team / oracle-team / trio (ตัวเขียนโค้ดภายนอกผ่าน tmux) Anthropic บอกต้นทุน "สูงกว่ามาก" แต่ละคนคือ session เต็ม memory ฟลีต: ทีม "ให้รายงานเก่ากับเสียงรบกวน" บูตตาย 50% ตอนแตกตัวที่สอง "เข้าคิว ≠ ส่งถึง"

Shape 5

Inline. One agent, many lenses, zero spawning.

ตัวเดียว หลายเลนส์ ไม่แตกเอเจนต์เลย

Free — but the lenses can't disagree honestly. They've read each other.

ฟรี แต่เลนส์เถียงกันจริงไม่ได้ เพราะมันอ่านกันมาแล้ว

/oracle-prism. Same five-lens shape as adversarial, agents removed, written 3½ hours later the same day. One agent writing five sections has already read its own earlier sections — self-consistency pressure. Rule 4 ("don't harmonize") is a plea, not a mechanism.

/oracle-prism โครงห้าเลนส์เดียวกับ adversarial แต่ถอดเอเจนต์ออก เขียนหลังจากนั้นสามชั่วโมงครึ่งวันเดียวกัน เอเจนต์เดียวเขียนห้าหัวข้อ ก็อ่านหัวข้อก่อนหน้าของตัวเองมาแล้ว กฎข้อ 4 ("ห้ามเกลี่ยให้ตรงกัน") เป็นคำขอร้อง ไม่ใช่กลไก

What they share

Every shape has one decider.

ทุกรูปทรงมีผู้ตัดสินหนึ่งเดียว

The whole industry landed here too. Group chat with no leader is the shape everyone abandoned.

ทั้งวงการก็มาลงตรงนี้เหมือนกัน group chat ที่ไม่มีหัวหน้าคือทรงที่ทุกคนทิ้งไปแล้ว

LangGraph supervisor, CrewAI hierarchical crews, Microsoft's Magentic manager, Google ADK's root agent, smolagents' manager — all one decider + specialists. AutoGen's free-form GroupChat went into maintenance mode Oct 2025. Three things converging: one decider, typed handoffs instead of chat turns, A2A/MCP protocols instead of framework wire formats.

LangGraph supervisor, CrewAI crew ลำดับชั้น, Magentic manager ของ Microsoft, root agent ของ Google ADK, manager ของ smolagents ทั้งหมดคือผู้ตัดสินหนึ่ง + ผู้เชี่ยวชาญ GroupChat เปิดกว้างของ AutoGen เข้าโหมดดูแลอย่างเดียว ต.ค. 2025 สามอย่างที่บรรจบ: ผู้ตัดสินหนึ่ง, handoff แบบ typed แทนผลัดกันพูด, โปรโตคอล A2A/MCP แทน wire format ของแต่ละเฟรมเวิร์ก

Rule 1 of 4

Run one worker first.

รันหนึ่งตัวก่อนเสมอ

A one-worker test takes 5 seconds. A three-worker failure takes 2 minutes.

ทดสอบตัวเดียวใช้ 5 วินาที สามตัวพังพร้อมกันใช้ 2 นาที

mother-oracle · 2026-04-07

Verbatim: "Before scaling Agent Teams to N parallel workers, always test 1 worker first … 1-worker smoke test = 5 seconds, 3-worker failed batch = 2 minutes." Catches auth gaps and tool errors before they multiply — e.g. three Haiku workers that all hit "your account does not have access".

ตรงตัว: "ก่อนขยาย Agent Teams เป็น N ตัวขนาน ให้ทดสอบ 1 ตัวก่อนเสมอ … smoke test 1 ตัว = 5 วินาที batch 3 ตัวที่พัง = 2 นาที" จับปัญหาสิทธิ์กับเครื่องมือได้ก่อนจะทวีคูณ เช่น Haiku สามตัวที่เจอ "บัญชีไม่มีสิทธิ์" พร้อมกัน

Rule 2 of 4

Check the question before the swarm.

ตรวจคำถามก่อนปล่อยฝูง

Agents work inside the frame. They can't tell you the frame is wrong.

เอเจนต์ทำงานอยู่ในกรอบ มันบอกไม่ได้ว่ากรอบผิด

mawjs-oracle · premise-check · 2–5 minutes

Verbatim: "Evaluators optimize inside the frame … they cannot validate the frame itself. Convergent answers within a wrong frame look like high confidence but are actually correlated wrong answers." This is the rule the papers don't have — and MAST says 42% of failures live exactly here.

ตรงตัว: "ตัวประเมินทำงานอยู่ในกรอบ … มันตรวจตัวกรอบเองไม่ได้ คำตอบที่ตรงกันในกรอบที่ผิด ดูเหมือนมั่นใจสูง แต่จริง ๆ คือผิดพร้อมกัน" นี่คือกฎที่งานวิจัยไม่มี แล้ว MAST บอกว่า 42% ของความล้มเหลวอยู่ตรงนี้พอดี

Rule 3 of 4

Stop when they agree, not when the budget runs out.

หยุดตอนพวกมันเห็นตรงกัน ไม่ใช่ตอนงบหมด

Three agents debating past twenty minutes on the same answer: stop.

สามเอเจนต์ถกกันเกินยี่สิบนาทีบนคำตอบเดียวกัน หยุดได้แล้ว

mawjs-oracle · 2026-04-17

Verbatim: "When 3-agent debates run past ~20 minutes and converge on the same answer, stop the debate … multi-round debates cap at convergence, not budget." Research agrees: multi-agent debate gains flatten after 2–3 rounds / 3 agents.

ตรงตัว: "พอการถกเถียง 3 เอเจนต์เลย ~20 นาทีแล้วบรรจบที่คำตอบเดียวกัน ให้หยุด … การถกหลายรอบมีเพดานที่จุดบรรจบ ไม่ใช่ที่งบ" งานวิจัยเห็นด้วย ผลของ debate แบนหลัง 2–3 รอบ / 3 เอเจนต์

Rule 4 of 4

Trust the smoke test, not the reviewer.

เชื่อ smoke test ไม่ใช่เชื่อคนรีวิว

Review agents say "needs work" forever. If the thing runs, it works.

เอเจนต์รีวิวบอก "ยังต้องแก้" ได้ตลอดกาล ถ้าของรันได้ ก็คือใช้ได้

transcriber-oracle · 2026-06-18 · 13 → 3 → 1 → 1

Critical findings per round: 13, 3, 1, 1. Round 1 was real. Rounds 2–4 were guards round 1 had added, overshooting. Verbatim: "chasing it past convergence is negative-ROI." Ground truth was the booklet smoke-testing to 14 pages three times.

ข้อวิกฤตต่อรอบ: 13, 3, 1, 1 รอบแรกของจริง รอบ 2–4 คือด่านที่รอบแรกใส่เข้าไปแล้วเลยเถิด ตรงตัว: "ไล่ตามเลยจุดบรรจบคือติดลบ" ความจริงคือ booklet ผ่าน smoke test 14 หน้า สามครั้ง

The fleet's own idea

When two agents agree on their own, that's evidence.

พอสองเอเจนต์เห็นตรงกันโดยไม่ได้นัด นั่นคือหลักฐาน

Every framework calls duplicate work waste. The fleet calls it a second opinion — as long as they didn't share the frame.

ทุกเฟรมเวิร์กเรียกงานซ้ำว่าสิ้นเปลือง ฟลีตเรียกว่าความเห็นที่สอง ตราบใดที่ไม่ได้ใช้กรอบเดียวกัน

mawjs-oracle 2026-04-16: "when two oracles of shared lineage independently research the same technical question and arrive at the same answer, that convergence is materially stronger evidence than a single-oracle decision." The ensemble papers agree — 15 copies of Llama2-13B match Llama2-70B; debate lifts arithmetic from 67% to 82%. The caveat is Rule 2.

mawjs-oracle 2026-04-16: "พอ oracle สองตัวที่สายเลือดเดียวกัน ค้นคำถามเดียวกันแยกกันแล้วได้คำตอบเดียวกัน จุดบรรจบนั้นคือหลักฐานที่หนักแน่นกว่า oracle เดียวมาก" งานวิจัย ensemble เห็นด้วย Llama2-13B 15 ตัวเทียบ Llama2-70B ได้ debate ดันเลขคณิตจาก 67% เป็น 82% ข้อยกเว้นคือกฎข้อ 2
